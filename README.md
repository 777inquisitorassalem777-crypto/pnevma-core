# PNEVMA-CORE Ω — Unified Symbiosis

**Единый проект всего чата:** функциональная пневма + этика + безопасность + эволюция + опциональный славянский культурно-лингвистический слой.

Version: **2.0-unified**  
Status: Research scaffold (executable)  
License: MIT

## Что это

Очищенный и объединённый результат всей линии разработок:

- SymbioCore / SymbioPneuma
- Stallion / Stalion Sigma (safety, constitution)
- Slavic Semantic Core (волхв, ведун, заговоры, обереги, символы)
- Ethical gyroscope, paradigm library, intuition, ledger

**Это не** система создания сознания или переноса души.
Термины «пневма», «искра», «одухотворённость» — исследовательские метафоры и функциональные прокси.

## Архитектура

```
pnevma/
├── pneuma/         # состояние: ценности, непрерывность, неопределённость
├── philosophy/     # гуны, non-harm, этический гироскоп
├── safety/         # конституция (нельзя отключить)
├── evolution/      # propose → validate → integrate
├── intuition/      # новизна и нестандартные решения
├── edge/           # абстрактные сенсоры/актуаторы (proposal-only)
├── paradigms/      # append-only библиотека
├── ledger/         # provenance
└── slavic/         # ОПЦИОНАЛЬНО: лексика, символы, обереги, заговоры
```
