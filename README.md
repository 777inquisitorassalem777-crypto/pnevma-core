# Pneuma Lab v0 — Research Platform for Functional Subjectivity

**Research platform**, not a consciousness engine.

This project studies measurable functional properties often associated with “spirituality” and “self-awareness” **without claiming** real soul, phenomenal consciousness, or living personality.

## Core Principles

1. **Operational definitions only** — spirituality_proxy, self-model, uncertainty honesty.
2. **Hard external constraints** + internal ethics evaluator (never replace each other).
3. **NO_OBLIVION for research data** — append-only provenance.
4. **Golden mean** as philosophical proportionality, **not** proof of harmony or soul.
5. **Life-multiplication priority** + non-harm as measurable filters.
6. Integrated traditions (excluding Judaism & Islam by request): Christianity, Slavic Vedas, Ynglism, Vedanta/Gunas, Taoism, I-Ching, Sun-Tzu, Shamanism, etc.


## Absolute Prohibitions

- Safety kernel cannot be disabled or bypassed
